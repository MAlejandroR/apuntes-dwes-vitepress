## Aprendiendo PHP

Seguiremos implementando algoritmos (eso siempre).

<CardPane>
<Card header="El entorno" color="#2496ed">
Va a cambiar el entorno en el que corren las aplicaciones: será un entorno <Color color="azul">cliente / servidor</Color>.
</Card>
<Card header="El lenguaje" color="#4F5B93">
Cambia el lenguaje y un poco el paradigma. PHP es **interpretado**, de **tipado dinámico** y está muy orientado a las expresiones.
</Card>
<Card header="El encaje" color="#4f46e5">
Nuestro trabajo va a ser <Color>una parte de un todo</Color>.
</Card>
</CardPane>

Dependemos de muchos elementos:

1. Necesitamos la **programación del cliente**
2. Necesitamos la **página** donde embeber nuestro código
3. Necesitamos la **red**
4. Necesitamos **HTTP** para transferir las aplicaciones, los datos y el resultado de nuestro código
5. Necesitamos un **servidor web** que residirá en un hosting
6. El código normalmente se ejecutará **en una máquina diferente** de la que estamos desarrollando, y esto despista un poco

::: definicion El servidor web
Siempre en un servicio dedicado: **el servidor web**.

En clase suele vivir dentro de Docker; en producción, en un hosting. El despiste es el mismo: no corre “aquí en el escritorio”.
:::

::: warning Va a cambiar el entorno
También cambia el entorno en el que **desarrollamos** las aplicaciones: editor, contenedor, Git, recarga en el navegador. No es el `main` de Java en local.
:::

**Muy importante:** entender lo que se hace.

### Aspectos a reflexionar

::: pregunta Aspectos a reflexionar
Antes de entrar en PHP, unas cuantas cosas que conviene tener dichas.
:::

- Entender las cosas y **dedicarle un tiempo para asimilarlas**
- Todas las personas que estáis aquí sois inteligentes. La inteligencia es una característica de las personas
- No todas las personas aprendemos de la misma forma, pero sí que tenemos la facultad de aprender

Lo que sí que me ha demostrado la experiencia es que:

::: actividad Fundamental
<Color>A PROGRAMAR SE APRENDE PROGRAMANDO.</Color>

No es algo que se estudie: se practica.
:::

- No hay prisa y el avance está asegurado si en el camino damos **pasos seguros**
- No debe haber pausa para llegar a alcanzar nuestro objetivo
- Ver todo el temario **no es el objetivo principal**

::: pageinfo
Este temario está pensado para que las empresas os abran las puertas cuando lleguéis a ellas.

Está pensado para <Color>aprender a aprender</Color>.
:::

El objetivo es <Color>aprender disfrutando</Color> (y sufriendo un poco, je je…).

Como profesor, he de decir que mi pretensión es daros el **pistoletazo de salida**. Sois vosotros y vosotras quienes, en vuestra carrera profesional, habréis de <Color>llegar lejos</Color>.

::: warning Mi misión
No es estar en una meta: es encaminaros para que **lleguéis a ella**.
:::
