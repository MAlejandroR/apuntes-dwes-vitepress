::: objetivos Lo mínimo del servidor
- Moverse por directorios y ver permisos
- `chmod` / `chown` sin miedo (y sin romper `/var/www`)
- Entender que Apache corre como `www-data`
:::

El material largo de permisos, `tar` y propietario de `/var/www/html` está en [PhpStorm y permisos](/02_entornos_herramientas/instalaciones/phpstorm).

Esta página es el **listado de comandos de clase** (tú lo irás llenando): `ls`, `cd`, `pwd`, `tree`, `nano`/`vim`, `sudo`, `systemctl`, `a2ensite`, `ping`, etc.

::: pageinfo
Cuando un comando aparezca en Apache o Docker, enlacéalo aquí para que Linux no quede perdido dentro de otro tema.
:::
