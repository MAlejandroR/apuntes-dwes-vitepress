Un vistazo **muy por encima**. No es un módulo de IA; es una norma de aula.

## Qué vamos a usar

Completa aquí las herramientas concretas (ChatGPT, Copilot, Cursor, etc.) y la versión que recomendamos este año.

## Cómo la uso yo en clase

- Para **desatascar** un error que ya has leído
- Para **proponer** un nombre, un test o una refactorización
- Para **explicar** un fragmento que no pillas, pidiendo que no reescriba todo el ejercicio

## Cómo no

- Pegar el enunciado entero y entregar la respuesta
- Subir secretos, `.env` o datos de compañeros
- Aceptar código que no sabrías mantener en la pizarra

::: warning La IA sugiere; tú decides
En el examen no hay chat. Si no puedes explicar una línea, no es tuya.
:::
