::: objetivos El mismo laboratorio para todos
- Imagen, contenedor y volumen
- Un `Dockerfile` y un `compose` que levanten PHP + Apache
- Al menos **una semana (~8 h)** de clase, no un recorte de 20 minutos
:::

Docker es el entorno que vamos a usar de verdad. Los recortes de `docker-compose` y el `Dockerfile` ya están en [Instalaciones](/02_entornos_herramientas/instalaciones/) (y se repiten un poco en [PhpStorm y permisos](/02_entornos_herramientas/instalaciones/phpstorm)).

Esta página es el **hueco de la semana Docker**: prácticas, diagrama del flujo y lo que no cabe en la ficha de instalación.

::: pageinfo
Cuando rellenes esta unidad, conviene dejar por escrito:

1. Qué hay que tener instalado el primer día (Docker Desktop / motor en Linux)
2. Cómo se entra a `http://localhost:8800` (o el puerto que fijemos)
3. Dónde se escribe el código (`./app` mapeado a `/var/www/html`)
4. Qué hacer si “el contenedor no arranca”
:::

Documentación de partida: [docs.docker.com/get-started](https://docs.docker.com/get-started/).
